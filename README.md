# Runku-ho

Project to create a chatbot using a model fine-tuned in LoRA on my novel "[La Guerre Sacrée](https://la-guerre-sacree.fr/)", and enhanced with a RAG.

Runko-ho means “scribe” in Taki Zoraï, the language of a race in the universe of my novel.

The README will be updated at the end of the project to detail how it works.
